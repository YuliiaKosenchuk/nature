# Nature Guardians — Nonprofit environmental organization website
 
A responsive and user-friendly website for a nonprofit environmental organization. Users can learn about the mission, explore ongoing projects, read blog posts and news, discover upcoming events, and make donations to support the cause.

**This project was collaboratively built by me and [**Kyrylo Hasan**](https://github.com/Kirill1908).**
 
## 🔗 Live Demo
Experience the live website: [**Nature Guardians**](https://guardians-org.vercel.app/)
 
## 🖥️ Technologies Used
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Jira (Project management & task tracking)
- Git/GitHub (Collaborative version control)

## 🤝 Collaboration & Workflow
This project highlights a strong collaborative effort:
- **Development repository** [**here**](https://github.com/Kirill1908/Nature-Guardians)
- **Pair Programming:** Developed from scratch by two frontend developers working in tandem.
- **Agile Management:** All sprints, feature requests, and bug tracking were managed systematically using **Jira** boards to ensure a smooth and efficient development lifecycle.

## ✨ Features
- **Home Page** — hero section with a call to action and overview of the organization's mission
- **About Us** — team introduction, awards, and how donations are spent
- **What We Do** — description of environmental programs and initiatives
- **Media** — latest news and upcoming events
- **Contact Us** — contact form for reaching out to the organization
- **Donation** — options and instructions on how to contribute financially
- **Blog** — articles and posts on environmental topics
- **Events** — overview of upcoming and past events with details
- Fully responsive design for desktop, tablet, and mobile devices
 
## 🚀 Getting Started
To set up the project locally, run the following commands:

### 1. Clone the repository
```bash
git clone https://github.com/YuliiaKosenchuk/nature.git
cd nature
``` 
### 2. Install dependencies
```bash
npm install
# or
yarn install
```
### 3. Run the project locally
```bash
npm run dev
# or
yarn dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
